# 手作蜡模试制流程追踪与质检归档平台

面向手作蜡模小批量试制场景的工艺协同系统，用于串联款式要求、蜡料炉次、模具适配、台位安排、试制批次、过程记录、质检结论、返工处理和交付归档。项目重点不是通用后台、权限系统或库存台账，而是把蜡模试制从排产到交付的关键节点沉淀为可追踪、可复核的工艺记录。

## 项目亮点

- 试制批次全流程跟踪：覆盖待浇注、成型中、待质检、返工中、可交付、已交付等状态。
- 工艺过程记录：记录浇注、脱模、修整、气泡、返工等关键工序数据。
- 质检与返工闭环：支持尺寸偏差、表面平整度、质检意见、返工原因和返工次数留痕。
- 交付复核归档：交付前形成质量结论，交付后保存接收方、交付件数和归档备注。
- 工艺预警：围绕待质检、超期返工、待交付复核等节点提供提醒。
- 工艺资料配置：维护款式要求、蜡料炉次、模具适配、台位能力和质检周期，为试制流程提供约束。

## 技术栈

- 前端：Vue 3、TypeScript、Vite、Element Plus、Pinia、ECharts
- 后端：FastAPI、SQLAlchemy
- 数据模型：协同人员、款式要求、蜡料炉次、模具、台位、试制批次、过程记录、质检记录、返工记录、交付复核、交付归档

## 启动方式

```bash
npm install
npm run dev
```

后端依赖位于 `backend/requirements.txt`，可根据本地 Python 环境安装后启动 FastAPI 服务。
